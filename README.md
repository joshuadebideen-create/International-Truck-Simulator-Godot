
# International Truck Simulator

A mobile 3D truck-driving prototype built with Godot 4.

## Current prototype features

- 3D road and outdoor environment
- Basic truck model
- Accelerate and brake touchscreen buttons
- Left and right steering controls
- Chase camera
- Speed display in km/h
- Basic driving physics

## Project files

- `project.godot` — project configuration
- `scenes/main.tscn` — main game scene
- `scenes/truck.tscn` — truck physics scene
- `scripts/main.gd` — world, truck appearance, camera and interface
- `scripts/truck_controller.gd` — basic truck movement
- `scripts/mobile_controls.gd` — touchscreen controls

## Open the project

1. Install Godot 4 on a compatible device.
2. Download or clone this repository.
3. Open the folder containing `project.godot` in Godot.
4. Open `scenes/main.tscn`.
5. Run the project.

## Important

This is an early prototype. It does not yet include realistic truck models,
trailers with independent physics, AI traffic, multiplayer, damage systems,
sound systems, or a finished Android APK export setup.
